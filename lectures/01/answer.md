# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：「分からない」とは答えず、「難易度別」「AI活用レベル別」など、推測で3つの分け方を挙げた。
- 用語集の正しい意味と比べて気づいたこと：一般的な用語の LoRA の質問は、用語集の説明とおおむね合っていた。一方、宿題の3レベルの質問では、正しくは「基礎・実装・発展」のどれか1つで完了（原則採点なし）だが、モデルは推測で3つの分け方を挙げ、「基本は『レベル1』から順に（時間があれば全クリアを目指す）」と、逆のことを勧めた。講座に固有のことは、間違える可能性が高いので注意が必要。
- 表示できたトークン数（入力 / 出力）：宿題の3レベルの質問で 21 / 742

## 宿題

- 取り組んだレベル：基礎
- やったこと：同じ質問「AIE2026の講座の宿題にある『3レベル』とは何ですか？」を、`AIE_MODEL` で `gemini-3.5-flash-lite` と `gemini-3.5-flash` に切り替えて、3回ずつ実行した。
- 結果：

  | モデル | 出力トークン数（1 / 2 / 3回目） | 回答 |
  |---|---|---|
  | `gemini-3.5-flash-lite` | 522 / 435 / 396 | 3回とも、難易度の3段階と推測した |
  | `gemini-3.5-flash` | 540 / 526 / 662 | 3回とも、難易度の3段階と推測し、「レベル1は『必須』」などと断定した |

  - 同じモデル・同じ質問でも、長さと文面は毎回変わった。
  - 6回とも、正しい答え（基礎・実装・発展）にはならなかった。
- 気づき・疑問：上位のモデル（`gemini-3.5-flash`）は、既定のモデル（`gemini-3.5-flash-lite`）より長く詳しく答えたが、講座を知らない点は同じで、「レベル1は『必須』」「受講者全員がクリアすべき基本ライン」と誤りを断定した（正しくはどれか1つで完了）。モデルを変えても、知らない情報は正しく答えられない。最適なモデルの選び方について、学びを深めたい。
